# RetailPulse

AI-powered predictive dashboard for Quincaillerie du Rwamagana.

## Project structure

```
RetailPulse/
├── frontend/   # React + TypeScript + Vite app
└── backend/    # API placeholder (Spring Boot / FastAPI)
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173

## Backend

```bash
cd backend
mvn spring-boot:run
```

API: http://localhost:8080/api — see [backend/README.md](backend/README.md) for setup and demo accounts.
